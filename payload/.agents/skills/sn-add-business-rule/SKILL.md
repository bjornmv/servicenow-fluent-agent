---
name: sn-add-business-rule
description: Author a Fluent BusinessRule correctly — explain-first, script externalized via Now.include, primitive when/order/active. Use when adding server-side business logic (a business rule) to a now-sdk app.
argument-hint: <business rule name, e.g. set_priority_on_insert>
---
Author a new BusinessRule (named from the argument) in the current project scope from `now.config.json`. Use `now-sdk` directly in VS Code PowerShell; in Pi use the `now_sdk` tool with arguments and project `cwd`. See the [SDK command policy](../../reference/sdk-commands.md).

1. FIRST run `now-sdk explain businessrule-api --format raw`. Only run `now-sdk explain business-rule-guide --format raw` if this is the FIRST business rule in the project or the trigger pattern is unfamiliar. (Or run the **sn-explain** skill.) If `/memories/repo/businessrule-api.md` does not yet exist, cache a 5–10 line summary of the explain output there — required/optional fields, the standard signature — so the next business rule in this project skips the explain round-trip.
2. Create `src/fluent/server-development/business-rule/<name>.now.ts` with `BusinessRule({...})` — this follows the server-development category layout for hand-authored rules. Do not put new hand-authored rules under `src/fluent/generated/`; leave round-tripped transform files there. Set `script: Now.include('../../../scripts/<name>.js')` because `Now.include` paths are relative to the `.now.ts` file (3 folders deep → 3 `..`) — NEVER an inline function body.
3. REQUIRED properties — the build fails without them: `$id: Now.ID['<stable_key>']` (BusinessRule is typed `WithID`; omitting it fails TS2345 / "Failed to determine ID" — pick a stable key like `br_<name>`, it becomes the record's identity in `keys.ts`) and `table` (the table the rule fires on). Then set `when`, `order`, `active` as primitives (e.g. `when: 'before'`, `order: 100`, `active: true`) — never `'true'`/`'100'` strings. Apply the [Fluent rules](../../instructions/fluent.instructions.md): no `||`/`&&`/`?:`/`+`-concat anywhere in the file (const initializers included), no control flow, `const` only, no unused consts.
4. Create `src/scripts/<name>.js` with the actual rule logic — full JS/TS is allowed there (`if`/`for`/etc. fine). Standard signature: `(function executeRule(current, previous) { ... })(current, previous);`.
5. Run `now-sdk build` to verify it compiles. Report the build output; fix any Fluent syntax errors (see the **sn-fix-build** skill) and rebuild before stopping.
